DK FOOTWEAR — WEBSITE SETUP (SPCK EDITOR)

FILES
- index.html    Home page
- products.html Product collection, filters, search and cart
- about.html    About page
- contact.html  Contact page
- style.css     Shared luxury black-and-gold styling
- script.js     Product catalogue, cart and WhatsApp ordering

RUN ON ANDROID / SPCK
1. Open SPCK Editor.
2. Create a new project (or open your existing project).
3. Add all 6 files above in the project root. Copy each file's complete content into the matching filename.
4. Save all files.
5. Open index.html and tap Preview.
6. Test the nav links, product filters, Add to bag and WhatsApp checkout.

WHATSAPP

IMPORTANT CUSTOMISATION
- Product names, categories, prices and image URLs are at the top of script.js in PRODUCTS.
- Product photos are remote Unsplash image URLs, so internet is required for images. Replace them with your own genuine product photos for the real shop.
- Prices, availability and product descriptions are sample/demo content. Confirm them before taking orders.
- The cart uses browser localStorage and is not a payment system.
- WhatsApp ordering opens a prefilled message; the customer must send it themselves.
- This is a static front-end website. It does not have a database, admin dashboard, payment gateway or stock management.
- Google Fonts and product images require an internet connection.
- To publish free, upload the project files to a GitHub repository and enable GitHub Pages in the repository's Settings > Pages. The website must remain a static site.
